# M4A Player

カラオケなどで録った m4a 音源をまとめて取り込み、音楽プレーヤーのように連続再生するiPhone用アプリです。
Safariで開いて「ホーム画面に追加」すると、普通のアプリと同じように使えます。

## できること

- m4a などの音源を複数まとめて取り込み（同じファイルの二重取り込みは自動でスキップ）
- 「ファイル」アプリからまとめてドラッグ＆ドロップで追加
- 連続再生、前へ／次へ、シャッフル、リピート（全曲／1曲）
- 画面下のタブで「ライブラリ」「追加」「設定」を切り替え
- ライブラリはフォルダ一覧（すべての曲／未分類／自分のフォルダ）から開く形式
- フォルダ分け（作成・名前変更・削除、複数選択でまとめて移動）
- 曲を左にスワイプで「移動」「削除」ボタン（大きくスワイプでそのまま削除）
- 並び替え（新しい順／古い順／名前順／長い順）、名前検索、名前の変更
- 再生速度（0.75×〜2×）、15秒戻る／進む、実際の音声から作る波形でのシーク
- ロック画面・コントロールセンターからの操作、画面を消しても再生継続
- 前回の続きから再開、オフラインでも起動

音源はiPhoneの中（ブラウザの保存領域）にだけ保存されます。サーバーには何も送りません。

## 1. 公開する（家のPCで1回だけ）

ホーム画面アプリにするには HTTPS のURLが必要です。GitHub Pages（無料）が簡単です。
公開されるのはアプリの部品だけで、音源は含まれません。

Claude Code にこのフォルダを開かせて、次のように頼めばOKです:

```
このフォルダを GitHub の新しいリポジトリ m4a-player に push して、
GitHub Pages（main ブランチのルート）で公開して。公開URLを教えて。
```

手動でやる場合:

1. GitHub で新しいリポジトリ `m4a-player` を作る（Public）
2. このフォルダの中身をそのまま push
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/m4a-player/` で開ける

（GitHubを使いたくない場合は https://app.netlify.com/drop にフォルダをドラッグするだけでも公開できます）

## 2. iPhoneに入れる

1. iPhoneの **Safari** で公開URLを開く
2. 共有ボタン → **「ホーム画面に追加」**
3. ホーム画面の **M4A Player** から起動する

**取り込みは必ずホーム画面のアイコンから起動した状態で行ってください。**
Safariで開いたページとホーム画面アプリは保存領域が別です。

## 3. 音源を取り込む

### 基本の流れ

1. ボイスメモで録音を選んで 共有 → **「"ファイル"に保存」**。いつも同じフォルダ（例: iCloud Drive の「カラオケ」）に保存する
2. M4A Player の下の **追加** タブ → 追加先のフォルダを選ぶ → **ファイルから選ぶ** → そのフォルダで **「選択」→「すべて選択」→ 開く**

取り込み済みの曲は自動でスキップされるので、毎回フォルダ全体を選んでも大丈夫です。
ライブラリでフォルダを開いて右上の「＋」を押しても、そのフォルダに直接入ります。

### ドラッグ＆ドロップ（ボイスメモから直接）

1. ボイスメモで録音を長押しして、少し動かして持ち上げる（LINEに送るときと同じ操作）
2. 持ったまま、別の指で他の録音をタップすると複数まとめて持てる（ボイスメモ側が対応していれば）
3. 持ったまま画面下端から上にスワイプしてホームに戻り、M4A Player を開く
4. 画面のどこかに落とすと取り込まれる

「ファイル」アプリからも同じ操作でまとめて入れられます。

### 共有メニューから1タップで保存（ショートカット）

Webアプリは iPhone の共有メニューに直接出せません（Safariが未対応のため）。
代わりに「ショートカット」アプリで、共有メニューから決まったフォルダへ一発で保存するボタンを作れます。

1. 「ショートカット」アプリ → ＋ で新規作成、名前を「カラオケに保存」にする
2. アクション **「ファイルを保存」** を追加し、「保存先を尋ねる」をオフにして、保存先に「カラオケ」フォルダを指定
3. 下の「i」（詳細）→ **「共有シートに表示」** をオン

これでボイスメモの共有メニューに「カラオケに保存」が出ます。あとはM4A Playerの「追加」でそのフォルダを丸ごと選ぶだけです。

## 注意

- ホーム画面のアイコンを削除すると、取り込んだ音源も消えます（元のファイルは消えません）
- 保存できる量はiPhoneの空き容量に応じて決まります。「設定」タブで使用量を確認できます
- アプリを更新したら、GitHubにpushし直すだけで次回起動時に反映されます。音源データはそのまま残ります

## ファイル構成

- `index.html` … アプリ本体（画面・再生・保存の処理すべて）
- `sw.js` … オフライン起動用
- `manifest.webmanifest`, `icons/` … ホーム画面用の名前とアイコン
